# tidyhwsd 0.2.0

- Default extraction returns dominant components to match legacy behavior.
- Added composition workflow via `hwsd_compose()` and aggregation rules in `hwsd_props()`.
- Expanded property metadata with precision and clarified units.
- Updated documentation and examples to reflect dominant vs. composed outputs.

# tidyhwsd 0.1.0

- Initial tidyverse-style interface to HWSD v2.0.
- Download helper for the HWSD grid, point/bbox extraction with tiling, property listing.
- ggplot2 helper `geom_hwsd_raster` for quick raster plotting.
